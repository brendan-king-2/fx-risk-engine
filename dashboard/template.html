Model scorecard

Kupiec tests whether the exception rate matches the target. Christoffersen tests whether exceptions cluster in time. Conditional coverage combines both. Z2 (Acerbi–Székely) checks the size of tail losses against Expected Shortfall: near 0 is good, below −0.70 rejects at roughly 5%. Quantile loss is the average pinball loss of the VaR forecast; lower is better. Click a row to chart that model.
